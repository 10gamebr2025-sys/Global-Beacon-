# ကမ္ဘာ့အလင်းတန်း — Global Beacon 🌐

မြန်မာဘာသာ ကမ္ဘာ့သတင်းဝက်ဆိုဒ်

## ဖိုင်များ
- `index.html` — ပင်မ website
- `admin.html` — Admin panel (သတင်းရေး၊ ကြော်ငြာ)

## စတင်အသုံးပြုနည်း

### ၁) API Key ထည့်ပါ
- [newsdata.io](https://newsdata.io) တွင် Register လုပ်ပါ (အခမဲ့)
- index.html ဖွင့်ပြီး `YOUR_NEWSDATA_IO_KEY` နေရာတွင် key ထည့်ပါ

### ၂) Netlify တွင် Hosting (အလွယ်ဆုံး)
1. [netlify.com](https://netlify.com) တွင် Account ဖွင့်ပါ
2. global-beacon folder ကို website ပေါ်တွင် drag & drop ချပါ
3. ပြီးပါပြီ! 🎉

### ၃) GitHub Pages တွင် Hosting
1. [github.com](https://github.com) တွင် Account ဖွင့်ပါ
2. New Repository ဖွင့်ပါ
3. ဖိုင် ၂ ခု upload လုပ်ပါ
4. Settings → Pages → main branch save လုပ်ပါ

## Features
- ✅ ကမ္ဘာ့သတင်း auto-fetch (NewsData.io)
- ✅ မြန်မာဘာသာ auto-translate
- ✅ Admin panel — ကိုယ်တိုင် သတင်းရေးနိုင်
- ✅ ကြော်ငြာ slot ၄ နေရာ
- ✅ Mobile responsive
- ✅ မြန်မာ cultural theme (ကမ္ဘာလုံးလိုဂို)
