💡 Google AdSense ဝင်ငွေ ရှာနည်း:
① google.com/adsense တွင် Apply လုပ်ပါ
② Approve ဖြစ်ပြီးပါက Ad code ရပါမည်
③ ထိုcode ကို ဤနေရာတွင် ထည့်ပါ
④ လူကြည့်တိုင်း ဝင်ငွေ ရမည်

🔑 NewsData.io API Key

အစစ်အမှန် ကမ္ဘာ့သတင်းများ ဆွဲရန် API key လိုသည်။ ယခု demo သတင်းများ ပြနေသည်။

  1. newsdata.io တွင် အခမဲ့ Register လုပ်ပါ
  2. Dashboard → API Key ကူးပါ
  3. index.html ဖိုင်တွင် YOUR_NEWSDATA_IO_KEY နေရာတွင် ထည့်ပါ

🌐 GitHub Pages — အခမဲ့ Hosting

Website ကို internet ပေါ်တင်ရန် အောက်ပါ အဆင့်များ လုပ်ဆောင်ပါ:

  1. github.com တွင် Account ဖွင့်ပါ
  2. New Repository → အမည်ပေး → Public ရွေးပါ
  3. index.html နှင့် admin.html ဖိုင်များ Upload လုပ်ပါ
  4. Settings → Pages → Branch: main → Save
  5. မိနစ် ၂-၃ အကြာတွင် username.github.io/repo-name တွင် live ဖြစ်မည်

📱 Netlify — အကောင်းဆုံး အခမဲ့ Hosting

GitHub ထက် ပိုလွယ်ကူသည် — drag & drop ပဲ လုပ်ရသည်:

  1. netlify.com တွင် Account ဖွင့်ပါ
  2. Dashboard တွင် folder ကို drag & drop ဆွဲချပါ
  3. ချက်ချင်း live ဖြစ်သည် — custom domain လည်း ချိတ်နိုင်သည်
